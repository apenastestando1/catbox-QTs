📸 Galeria QT Catbox
Galeria de imagens simples em um único arquivo HTML, que exibe e baixa imagens hospedadas no Catbox.

🔗 Demo: https://galeria-qt-cat.netlify.app/

⚠️ As imagens são hospedadas em serviço de terceiros (Catbox). A autoria e os direitos de cada imagem pertencem aos respectivos criadores.
